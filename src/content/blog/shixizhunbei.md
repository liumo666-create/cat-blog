# 电子信息工程大四实习冲刺路线

## 先说结论

你不需要在两个月里学完所有东西，更不要同时学嵌入式、前端、测试和运维。你现在最有优势的组合是：

**本科专业是电子信息工程 + 对 Linux 感兴趣 + 英语 CET-6 + 能借助 AI 做项目。**

建议把主要精力放在一条主线：

**首选：嵌入式软件 / 嵌入式 Linux 应用开发。**

如果两周后发现自己确实跟不动 C 语言和数据结构，就降到更容易先上岸的：

**备选：Linux 运维 / 技术支持 / 软件测试。**

这两条路线都能用到你的 Linux 兴趣，而且武汉本地都有实习岗位。

## 招聘市场实际在要求什么

我抓取和搜索了 Boss 直聘、校招就业网等公开 JD 摘要。嵌入式、Linux、前端、测试方向的高频要求大致如下：

**嵌入式软件 / Linux 开发实习：**

- C/C++，指针、结构体、内存管理、函数指针、位运算
- Linux 常用命令、文件权限、进程与线程、TCP/IP
- 数据结构和基础算法
- GCC、Makefile、GDB、Git
- 进阶会提到 STM32、ARM、UART/I2C/SPI、RTOS/FreeRTOS

**Linux 运维 / 技术支持 / 测试实习：**

- Linux 系统操作、Shell 脚本
- 网络基础：TCP/IP、HTTP、DNS
- MySQL 基础
- Python 或脚本语言
- Docker、Nginx、云平台、监控，属于加分项

**前端实习：**

- HTML、CSS、JavaScript/ES6
- Vue 或 React
- Git/GitHub
- 组件化、接口联调、响应式布局

**软件测试实习：**

- 测试用例设计、测试流程
- Linux 命令、SQL、HTTP
- Python 或 Postman、Fiddler 等工具

对你来说，**嵌入式路线学历和专业匹配度最高，后续天花板也更高；但入门曲线更陡。** 运维/测试路线更容易在 1 个月内达到面试门槛，但长期竞争力不如嵌入式扎实。

## 首选路线：嵌入式软件 / Linux 应用

目标岗位关键词：`嵌入式实习生`、`C/C++ 实习生`、`嵌入式软件实习生`、`Linux 开发实习生`、`物联网实习生`、`单片机实习生`。

### 第 1 周：Linux 环境与 C 语言热身

先不要把时间花在装各种发行版上，用 VMware/VirtualBox 装一个 Ubuntu 22.04/24.04 就够了，或者先用 WSL2。

必练内容：

- `ls`、`cd`、`cp`、`mv`、`rm`、`chmod`、`chown`、`ps`、`top`、`df`、`du`
- `grep`、`find`、`tar`、`systemctl`、`ssh`
- `vim` 基本操作
- 用户、组、文件权限，理解 `rwx`
- 环境变量、`PATH`、软件包安装

C 语言重点：

- 变量类型、数组、字符串、结构体
- 指针与数组的关系、二级指针、函数指针
- 栈与堆、`malloc/free`
- 位运算和结构体对齐
- 简单文件读写

每天至少手写 10 个短程序，不要只看视频。

### 第 2 周：Linux 系统编程基础

这一周决定你能不能过嵌入式/Linux 岗位的初筛。

- 进程：`fork`、`exec`、`wait`
- 线程：`pthread_create`、锁、互斥量
- 文件 I/O：`open/read/write/close`、`lseek`
- Socket：TCP 客户端/服务端、`bind/listen/accept`
- 信号、管道、共享内存先理解概念即可
- 使用 `gcc`、`Makefile` 编译，使用 `gdb` 调试

能写出一个多线程 TCP 服务端，就是很大的进步。

### 第 3 周：数据结构与算法

嵌入式实习虽然不像互联网那样卷 LeetCode，但链表、栈、队列、树、哈希表仍会问。

先掌握：

- 链表：单链表增删改查、反转链表
- 栈和队列：数组实现、链表实现
- 二叉树：遍历、层序、深度、镜像
- 哈希表：冲突解决思想
- 排序：冒泡、快排、归并
- 查找：二分查找

刷题平台用 LeetCode 或牛客。目标：

- 简单题 40 道左右
- 中等题 10 道左右
- 重点做链表、字符串、二叉树、二分

### 第 4 周：嵌入式专项

这里分两条支线，根据你的时间选一条：

**A. 偏向 MCU：**

- STM32 基础：GPIO、外部中断、定时器、串口
- UART、I2C、SPI 的基本时序概念
- FreeRTOS 的任务、队列、信号量

**B. 偏向嵌入式 Linux：**

- 交叉编译的概念
- 设备文件 `/dev`、字符设备
- `read/write/ioctl` 的基本理解
- 在树莓派或开发板上跑一个小程序

没有开发板也没关系，可以用 QEMU、WSL2、虚拟机模拟 Linux 环境，先把 C 和 Linux 系统编程基础打牢。面试时诚实说“有 Linux 应用层实践，开发板项目正在补”，比背概念强。

### 第 5 周：项目包装与面试

项目不要追求高大上，做一个能讲清楚的小项目：

1. **Linux 多线程 TCP 聊天/文件传输工具**
   - 用 C 实现服务端和客户端
   - 支持多客户端连接、并发处理
   - 讲清楚线程、socket、缓冲区、粘包问题

2. **简易日志系统或命令行工具**
   - 支持日志分级、写文件、多线程写入
   - 用 `getopt` 解析参数

3. **STM32 温湿度采集 + 串口上传**
   - 如果条件允许，做 GPIO、UART、定时器
   - 把传感器数据上传到电脑串口助手

每个项目都要写 README，上传 GitHub。面试官问你项目时，能回答“为什么这么设计、遇到什么问题、怎么解决”才算真正掌握。

## 备选路线：Linux 运维 / 技术支持 / 测试

如果你两周后发现 C 语言和系统编程确实痛苦，切换到这条路，先求上岸。

### 第 1-2 周

- Ubuntu 日常操作和 Shell 脚本
- 用户权限、进程、日志、计划任务
- 网络基础：TCP/IP、HTTP、DNS、端口
- 基础 MySQL：增删改查、简单查询

### 第 3 周

- Python 基础：文件处理、字符串、JSON、`requests`
- 写 2-3 个脚本：批量重命名、日志分析、接口检查
- Docker 概念和常用命令
- Nginx 基本配置：静态站点、反向代理、HTTPS

### 第 4 周

- 软件测试基础：测试用例、边界值、等价类
- 用 Python + `requests` 做简单接口测试
- 把你的 Astro 博客部署过程写成“独立完成的个人项目”：域名解析、DNS、HTTPS、Cloudflare Pages/CDN、持续部署

你的博客在这里是非常好的加分项。不要说自己“看不懂代码”，简历里可以写成：

- 使用 Astro 搭建个人技术博客
- 完成域名购买、DNS 解析和 HTTPS 配置
- 通过 Cloudflare Pages 实现静态站点托管与自动部署
- 使用 Git 管理项目并持续更新技术学习笔记

## 简历怎么写

针对嵌入式岗位，建议突出：

- 电子信息工程本科，2027 届或 2026 届，可实习 X 个月
- 熟悉 C 语言、Linux 常用命令、Git
- 了解 TCP/IP、进程/线程、Socket 编程
- 独立完成“Linux 多线程 TCP 通信工具”等项目
- CET-6，能阅读英文芯片手册和技术文档
- 学创杯湖北省一等奖，体现团队协作和项目落地能力
- 个人博客及 GitHub，体现持续学习和部署能力

针对运维/测试岗位，把 C 项目替换为 Shell/Python 脚本、博客部署、测试用例设计。

## 面试必背题

嵌入式方向优先准备：

- C 语言：指针和数组、`static`、`const`、`volatile`、内存四区、`malloc/free` 和内存泄漏
- Linux：常用命令、软链接硬链接、僵尸进程、进程和线程区别
- 网络：TCP 三次握手、四次挥手、TCP/UDP 区别、HTTP 和 HTTPS
- 数据结构：链表反转、二分查找、快排思想、栈和队列
- 项目：为什么做、架构怎么画、遇到什么 bug、怎么排查

运维/测试方向优先准备：

- Linux 权限、日志查询、查找文件、进程状态
- TCP/IP、HTTP 状态码、DNS 解析过程
- MySQL 基础查询、索引概念
- Docker 常用命令、Nginx 反向代理
- 测试用例设计方法、Bug 生命周期

## 学习资料建议

免费为主：

- Linux：菜鸟教程 Linux 教程、鸟哥的 Linux 私房菜选读
- C：菜鸟教程 C 语言、翁恺 C 语言程序设计
- 数据结构与算法：LeetCode、牛客题单
- 嵌入式：正点原子/野火 STM32 视频、FreeRTOS 官方文档
- Linux 系统编程：APUE 挑章节看，不必从头啃
- Git：廖雪峰 Git 教程
- 运维：Linux 就该这么学、Docker 官方教程

## 每天怎么安排

如果每天能投入 4 小时：

- 上午：知识点学习，手写代码
- 下午：做项目、刷题、记笔记
- 晚上：整理面试题，更新博客/GitHub

如果每天只有 2 小时：

- 周一到周五：路线主线
- 周六：补项目
- 周日：投递简历 + 复盘面试题

## 三个不要

1. 不要只看视频，代码一定要亲手敲。
2. 不要让 AI 直接写完整项目，先让它解释思路，再自己实现；面试时你必须能讲清楚代码。
3. 不要同时开三条技术路线，两个月里把一条做到能面试，比三条都只懂皮毛强。
